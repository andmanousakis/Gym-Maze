## MAJOR RELEASE - [1.0.0] - 2025-07-16

### Added
- Initial implementation of the 5x5 maze RL environment with Gymnasium API wrapper.
- Training scripts and configurations for DQN and PPO agents.
- Evaluation script for comparing agent performance.
- TensorBoard support for visualizing training metrics.
- Comprehensive PDF report and README documentation.
- Docker containerization for easy environment setup and deployment.
- FastAPI integration for exposing endpoints and interfacing with the RL agents.
- `make` commands for build, train, evaluate, clean.
